This Foundation patch does not pretend browser storage is shared storage. Data is currently saved locally in this browser, with explicit export/import so records can be moved safely while a shared backend is configured. The data model and UI are separated so a Google Apps Script, Cloudflare, or other Studio API can replace the local adapter without redesigning the workflow.
